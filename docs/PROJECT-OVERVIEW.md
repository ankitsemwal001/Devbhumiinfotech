# Project Overview — Devbhoomi Infotech

## 1. Executive Summary

**Devbhoomi Infotech** (`https://www.devbhoomiinfotech.com`) is a technology engineering and digital growth partner headquartered in Rishikesh, Uttarakhand, serving clients worldwide through remote project delivery.

The platform is engineered as a high-performance, static-export web architecture designed to:

1. Deliver rapid page loads and strong Core Web Vitals performance targets.
2. Serve clients globally via 5 core service groups in English, while anchoring local search presence in Uttarakhand (Rishikesh, Dehradun, Haridwar).
3. Power conversion through transparent pricing models, interactive WhatsApp integration, and automated lead capture.
4. Adhere strictly to Google Search Essentials, Schema.org linked `@graph` guidelines, and Generative Engine Optimization (AIO/GEO).

## 3. Technology Stack

### Core Framework & Runtime
- **Next.js 16**: App Router, static HTML generation with `output: "export"`, `trailingSlash: true`.
- **React 19**: Modern concurrent rendering, server and client component boundaries.
- **TypeScript 5**: Strict type safety across all data models, schemas, and components.
- **Node.js**: Modern JavaScript runtime for build-time scripting and audits.

### Styling & Design System
- **Tailwind CSS v4**: Modern CSS-first styling.
- **Radix UI Primitives**: Accessible, unstyled UI headless components (`@radix-ui/react-*`).
- **Lucide React**: Crisp vector iconography (`lucide-react`).
- **Framer Motion**: Smooth micro-interactions and transitions.

### Typography Stack
- **Brand / Editorial Heading**: `ibrand` (custom display font) & `Playfair Display` (editorial serif).
- **Body & Functional UI**: `Neue Plak` (Light, Regular, SemiBold, Bold) & `Plus Jakarta Sans`.

### Telemetry & Analytics
- **Google Tag Manager (GTM)**: Non-blocking script injection.
- **Google Analytics 4 (GA4)**: Event telemetry (`cta_click`, `form_start`, `form_submit`).
- **Google Consent Mode v2**: Default privacy-safe cookie consent banner (`granted` / `denied`).
