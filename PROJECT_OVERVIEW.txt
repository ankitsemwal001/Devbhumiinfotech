1. EXECUTIVE PROJECT SUMMARY
================================================================================
Devbhoomi Infotech Solutions is an enterprise-grade digital agency and IT services 
web platform built for Devbhoomi Infotech based in Rishikesh, Uttarakhand. 

The website serves as the primary commercial and lead generation platform for:
- Custom Full-Stack Website Development (React/Next.js)
- Responsive Website Design (UI/UX)
- Local & Technical SEO / Digital Marketing
- AI Workflow & Business Automation (Chatbots, n8n workflows, CRM automation)

Key Business Capabilities:
- Direct WhatsApp lead generation integration for instant customer conversions.
- Static HTML export optimized for ultra-fast CDN delivery and zero server cost.
- Comprehensive LocalBusiness & Service JSON-LD schema for local Rishikesh rankings.
- Modular architecture allowing rapid expansion of case studies, packages, and blogs.

4. TYPOGRAPHY & FONT SYSTEM
================================================================================
The project implements a bespoke multi-layer editorial typography hierarchy
combining self-hosted geometric sans-serif fonts with Google web fonts.

[A] LOCAL ASSETS (/public/fonts/)
--------------------------------------------------------------------------------
1. 'ibrand' (OpenType /public/fonts/ibrand.otf)
   - Usage: Primary agency branding, prominent display headings (h1, h3, h4, h5, h6).
   - Style: Distinct geometric modern serif-hybrid display font.
2. 'Neue Plak' Family (TrueType):
   - Neue Plak Light    (300 weight) -> /fonts/Neue-Plak-Light.ttf
   - Neue Plak Regular  (400 weight) -> /fonts/Neue-Plak-Regular.ttf
   - Neue Plak SemiBold (600 weight) -> /fonts/Neue-Plak-SemiBold.ttf
   - Neue Plak Bold     (700 weight) -> /fonts/Neue-Plak-Bold.ttf
   - Usage: Unified body copy, paragraph text, buttons, form elements, table data.

[B] REMOTE GOOGLE FONTS (Preconnected in layout)
--------------------------------------------------------------------------------
1. 'Playfair Display' (Weights: 400 to 900, Normal & Italic)
   - Usage: Editorial serif headings (h2), highlighted span tags, luxury accents.
2. 'Plus Jakarta Sans' (Weights: 400, 500, 600, 700, 800)
   - Usage: High-legibility web fallback for Neue Plak on UI copy.

[C] TYPOGRAPHIC HIERARCHY RULES (from globals.css)
--------------------------------------------------------------------------------
- <body>, <p>, <span>, <a>, <button>, <input>, <textarea>, <select>
  -> font-family: 'Neue Plak Regular', 'Neue Plak', 'Plus Jakarta Sans', sans-serif;
- <h1>
  -> font-family: 'ibrand', 'Playfair Display', sans-serif;
  -> letter-spacing: -0.02em;
- <h2>
  -> font-family: 'Playfair Display', 'ibrand', Georgia, serif;
  -> letter-spacing: -0.01em;
- <h3>, <h4>, <h5>, <h6>
  -> font-family: 'ibrand', 'Playfair Display', sans-serif;
  -> letter-spacing: -0.01em;

[D] UTILITY CSS FONT CLASSES
--------------------------------------------------------------------------------
- .font-ibrand            -> font-family: 'ibrand', sans-serif !important;
- .font-playfair          -> font-family: 'Playfair Display', Georgia, serif !important;
- .font-neue-plak         -> font-family: 'Neue Plak Regular', sans-serif !important;
